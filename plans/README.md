# Plans — the working record

These are the live working documents of the bring-up, included for the
record — engineering notebooks, not documentation. They contain dead ends,
falsified hypotheses, bench-specific paths (`/home/kyle/…`, two rooted
reference phones), and per-subsystem war stories, largely written by/with an
AI assistant during the work.

Start with:

- [PLAN.md](PLAN.md) — the map: status snapshot, the three-cluster model, the
  three-device methodology, index of everything else.
- [PLAN-release.md](PLAN-release.md) — the release tracker (phases, gates,
  repo worksheet).
- [PLAN-qmux.md](PLAN-qmux.md) / [PLAN-qmux-bridge.md](PLAN-qmux-bridge.md) /
  [PLAN-radio.md](PLAN-radio.md) — the multi-year modem saga and its solution.

Files named `*.old*.md` are superseded lanes kept for the archaeology.

(In the bench tree these files are symlinked back to their original spots at
the source-tree root, so in-tree references keep resolving.)
